Today I published the first version of this website.

I want to preserve the process of learning fluid simulation and rendering here, while explaining the mathematics behind them more clearly. Unlike assignments completed for a deadline, these articles can evolve over time, and the project pages can retain both experimental results and failed attempts.

## What comes next

- Complete the implementation notes for my 2D fluid solver.
- Organize the equations and diagrams from my real-time rendering studies.
- Add reproducible technical notes to every demo.

This website currently uses Astro to generate static HTML. No framework code runs in the visitor's browser, so the pages remain simple, fast, and easy to migrate.
